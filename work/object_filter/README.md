# FILTER

Аддон для управления видимостью объектов в сцене. Позволяет быстро скрывать, показывать и блокировать выделение объектов по типу, имени или коллекции — без необходимости искать каждый объект вручную.

Упрощает работу в сложных сценах, где нужно временно убрать лишнее из viewport.

## Функции

### By Type — фильтр по типу объекта

Для каждого типа (Mesh, Armature, Empty, Light, Camera):

- **Toggle** — скрыть/показать все объекты типа. Кнопка показывает количество видимых объектов
- **SEL** — выделить все видимые объекты типа в сцене
- **Lock** — заблокировать выделение объектов типа (невозможно кликнуть в viewport)

### By Name — фильтр по имени

- Введите часть имени (регистронезависимо)
- **Toggle** — скрыть/показать все объекты, содержащие паттерн
- **Select** — выделить совпадающие объекты

### Collections — фильтр по коллекциям

Для каждой непустой коллекции:

- **Toggle** — скрыть/показать все объекты коллекции
- **SEL** — выделить объекты коллекции

## Установка

### Extension (Blender 4.2+)

Preferences → Get Extensions → Install from Disk → `filter.zip`

### Addon (Blender 3.0+)

Preferences → Add-ons → Install → `filter.zip`

## Использование

1. Откройте Sidebar (N) → вкладка **FILTER**
2. Используйте кнопки напротив каждого типа для управления видимостью
3. Для фильтрации по имени — введите паттерн и нажмите Toggle или Select

## Требования

- Blender 3.0+ (addon) или 4.2+ (extension)
